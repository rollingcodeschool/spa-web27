# Stickers Nerds

Aplicación web para explorar stickers con diseños nerds. Está construida con React y Vite, y cuenta con páginas de inicio, información y una vista para rutas no encontradas.

## Características

- Interfaz adaptable a distintos tamaños de pantalla.
- Navegación entre Inicio y Sobre nosotros.
- Campo de búsqueda y galería visual de stickers.
- Estilos con Tailwind CSS.

> La búsqueda y las imágenes de la galería son elementos de muestra; todavía no cuentan con funcionalidad de búsqueda ni con un catálogo propio.

## Tecnologías

- React
- Vite
- React Router
- Tailwind CSS

## Requisitos

- Node.js
- npm

## Instalación y uso

Clona el repositorio y entra en su carpeta:

```bash

cd spa-app
```
